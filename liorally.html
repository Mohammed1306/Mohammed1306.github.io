LioRally

A rally racing simulation game. This project, created by a team of four enthusiastic students, simulates real-life vehicle behaviors and challenges the player in a racing context against artificial intelligences.

Key Features

Realistic Simulation: The game provides an immersive experience by accurately replicating vehicle behaviors, physics, and racing conditions.
Artificial Intelligence: Competitive AI opponents create dynamic and responsive challenges for players, adding a strategic dimension to each race.
Track Variety: Diverse tracks offer unique challenges, ranging from urban environments to rugged terrains and changing weather conditions.

Project code

This project was primarily developed using C#. Here are some details about the features I implemented:
Use of Splines for Track Physics: These distance calculations along splines are crucial for accurately managing track physics. They are used to determine vehicle trajectories, calculate potential collisions, and manage race logic, contributing to a realistic experience for players.
Distance Calculation via Splines: One of the key features I developed involves the precise calculation of distances between various game elements by following the track splines. This feature relies on specific algorithms to determine distances along the curves defined by these splines.
Integration with User Interface (UI): In addition to the technical aspects, I also contributed to integrating these features into the user interface. This includes visualizing distance calculations and graphical representation of spline-based trajectories, providing an immersive visual experience for players.
